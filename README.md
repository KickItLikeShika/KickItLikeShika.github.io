# kickitlikeshika.github.io

Ahmed Khamis's blog. GitHub Pages builds it with Jekyll on every push to `main`.

**Preview locally** (Ruby 3): `bundle install`, then `bundle exec jekyll serve --unpublished` and open
http://localhost:4000. `--unpublished` also shows posts marked `published: false`.

**Write a post:** add `_posts/YYYY-MM-DD-slug.md` that starts with `# Title`. Optional front matter:
`description` (the line under the title on the home page), `tag`, and `published: false` to keep it off the
live site.
